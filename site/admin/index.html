Attorney review

This page is for a Pennsylvania-licensed attorney. A run reads the session laws credited on Title 18, Chapter 61. Each act is one item, including an act that changed several sections. It then looks for other firearms session laws that are not already in the record. It tries to verify each item against an official page. Nothing here is on the public record until you approve it. A new run cannot be completed while any item is still waiting.
